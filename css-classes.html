CSS-классы и переменные

Эта страница — шпаргалка для своей темы. Проще всего менять переменные в блоке :root { … }: они влияют на всё приложение сразу. Классы пригодятся, если нужно поправить отдельный блок.

Переменные темы

Светлые значения — по умолчанию, тёмные — из css/themes.css. Своя тема может переопределить любую переменную.

Пример своей темы

:root {
  --bg: #0b1020;
  --card: #151f33;
  --text: #e2e8f0;
  --muted: #94a3b8;
  --accent: #818cf8;
  --accent-soft: #2a2f5c;
  --danger: #f87171;
  --border: #2b3a54;
  --surface-soft: #1b2740;
  --track: #2b3a54;
}

Вставь этот код в «Своя тема из CSS» → «Применить и сохранить».
